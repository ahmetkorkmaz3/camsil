Your screen is a dirty window.
Clean it.

Camsil is a small toy for the Mac. It puts dust, water spots, and fingerprints on your screen. Spray the glass with the bottle. Wipe it with the cloth until it shines.

How to play

Spray, wipe, shine.

You use the mouse and a few keys. At 95% clean, the session ends with a shine.

  • Left click
    SprayHold the button to spray water on the glass with the bottle.
  • Right clickorSpace
    Switch the toolChange between the bottle and the cloth.
  • 12
    Select a toolKey 1 selects the bottle. Key 2 selects the cloth.
  • Escor⌘Q
    QuitStop at any time. Camsil also quits after 2 minutes without input.

Tip: Spray first, then wipe the wet glass with the cloth. Dry wiping only spreads the dust.

Features

A dirty window that acts like a real one.

The glass gets wet, the water runs down, and the cloth squeaks.

Three types of dirt

Dust, water spots, and fingerprints cover the screen. Each type needs a different amount of work.

Water droplets

The droplets from the spray run down the glass. They dry in about 8 seconds.

Cloth squeak

The cloth makes a squeak sound on the glass. The pitch changes with the speed of your hand.

Progress and shine

A readout shows how clean the glass is. At 95% clean, the session ends with a shine effect.

GPU simulation

Metal runs the water and dirt simulation on the GPU, on top of a live image of your screen.

Stops by itself

Press Esc or ⌘Q to quit. If you do not touch the mouse or keyboard for 2 minutes, Camsil quits.

Privacy

Your screen stays on your Mac.

Camsil uses ScreenCaptureKit to get a live image of the main screen. It draws the dirt on top of this image.

  • No recordingsCamsil does not record or save the screen image.
  • No network accessThe app does not connect to the internet. No data leaves your Mac.
  • Open sourceYou can read all of the code on GitHub.
System Settings → Privacy & Security → Screen Recording

Install

Install with one command.

The command downloads the latest version from GitHub Releases, checks its SHA-256 value, and installs it in /Applications.

Apple Silicon Mac (M1 or later) macOS 14 or later Screen Recording permission 
# Install and update
curl -fsSL https://raw.githubusercontent.com/ahmetkorkmaz3/Camsil/main/install.sh | sh

# A specific version
curl -fsSL https://raw.githubusercontent.com/ahmetkorkmaz3/Camsil/main/install.sh | CAMSIL_VERSION=1.0.0 sh
Manual install
  1. Download Camsil-X.Y.Z.zip from the Releases page.
  2. Open the zip file. Move Camsil.app into /Applications.
  3. Open the app. macOS shows the "Apple could not verify" warning. Click Done.
  4. Open System Settings → Privacy & Security. Click Open Anyway.

The app is not notarized, so a file from a browser download shows this warning. The install command does not show it.

Uninstall 
osascript -e 'quit app "Camsil"'
rm -rf /Applications/Camsil.app
tccutil reset ScreenCapture com.ahmetkorkmaz.Camsil

The last command removes the Screen Recording permission.
